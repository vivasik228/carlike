# CarLike — визуальная система
Пользователь задал направление и запросил немедленную реализацию подробного ТЗ; новая процедура выбора стиля не требуется.
Концепция: автомобильный editorial. Кинематографичный широкий кадр, крупная узкая типографика, спокойная навигация. Три направления идут асимметричным рядом с собственной фотографией. Секции сменяют плотность: большой визуал, текстовая пауза, горизонтальные строки, галерея, графитовая форма.
Цвета — из ТЗ, акцент единой переменной --accent. Основа шрифта: локальный Manrope, заголовки: локальный Oswald с кириллицей. На мобильном кадр смещён к машине, заголовки меньше, все элементы в одной колонке.
Движение — единое появление hero, тонкий параллакс только на desktop без reduced motion, реакции на наведение и фильтрацию. Контент доступен без анимации.
Изображения — реальные лицензированные фотографии, без ИИ. По последнему указанию пользователя фон, созданный ИИ, исключен. Фотографии найдены через Google и Unsplash; обычная цветокоррекция, кадрирование и WebP. Они не являются мастерской или работами CarLike.

Hero дополнен вертикальным барабаном: центральное название контрастное, соседние уменьшены и приглушены, края закрыты градиентной маской. GSAP двигает весь список на одну строку за 560 мс с power3.inOut. Три стабильные копии позволяют замыкать цикл без перемонтирования. Высота строки адаптируется к мобильным и невысоким экранам. Основная фотография сохранена; остальные секции и визуальные токены не менялись.

Доработка по карточкам 01/02/03/05: информационные aside, до/после, ошибки/успех формы и юридическая заметка обходятся без отдельной коробки. Выбираемые направления и открываемые проекты остаются карточками. Отступы: --space-detail 8, --space-item 24, --space-heading 48 (mobile 32), --space-section 96 (mobile 64). Hero сохраняет собственную геометрию барабана. Тексты называют действие и результат; количественные ориентиры взяты из фактического каталога (3 направления, 12 услуг). Ошибки и пустые состояния показываются в потоке с понятным восстановлением, без новых декоративных подложек. Загрузка фотографии не перекрывает SSR-изображение без JavaScript.
