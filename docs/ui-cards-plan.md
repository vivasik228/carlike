# Доработка по карточкам 01, 02, 03, 05

Путь посетителя: выбрать одну из трёх групп услуг, прочитать условия и оставить заявку либо позвонить. Сохранить фотографии, цвета, шрифты, Hero-барабан, структуру услуг и юридический смысл согласия.

1. Контейнеры: убрать 6 из 8 декоративных обрамлений (aside, два блока до/после, ошибка формы, успех формы, юридическая заметка). Карточки направлений/проектов, поля ввода, карта и cookie-диалог выполняют действия и остаются. Не удалять структурные DOM-узлы ради числа.
2. Отступы: 8 px внутри связанного элемента, 24 px между элементами, 64–96 px между секциями. На desktop 96 px, mobile 64 px; между заголовком и содержимым 48/32 px. Упорядочить form/grid/row spacing, сохранить адаптивные высоты Hero.
3. Текст: конкретные услуги и действия, 3 направления/12 услуг только как проверяемые факты; без выдуманных цен, процентов, сроков или гарантий. Ссылка открывает условия услуги, форма оставляет заявку на согласование.
4. Состояния: явная загрузка согласия и отправки с таймаутом/очисткой, повтор после ошибки, сохранение введённых данных, успех только после подтверждения API; пустая галерея и фильтр с восстановлением; загрузка/ошибка/повтор фотографий.

Проверка: meaningful tests сетевых ответов и таймаута; полный существующий suite, TypeScript/ESLint/build; desktop/mobile и форма в браузере, HTTP QA, review последних изменений. Браузерные изменения только через CUA, тестовые ответы сервера отдельно в автоматических тестах.
