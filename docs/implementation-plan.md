# CarLike Implementation Plan
> Execution: executing-plans, inline. Спецификация — исходное ТЗ пользователя.
Goal: полноценный коммерческий сайт с безопасным серверным приемом заявок.
Architecture: серверные страницы Next.js; клиентские острова меню, галереи, формы и аналитики; централизованные данные; SQLite на одном сервере в РФ, AES-256-GCM для содержимого заявок.

- [x] Основа: конфигурация, типы, локальные шрифты, реальное hero-фото с обычной обработкой, дизайн-токены.
- [x] Главная, направления, все подтвержденные услуги, контакты, демонстрационные проекты.
- [x] Интерактивность: адаптивное меню с фокусом, фильтры, lightbox, форма, cookie choices.
- [x] Сервер: тесты отказа без согласия, неизвестной услуги, даты, неправильного телефона; шифрование, idempotency, rate limit, ограничение размера и Origin; запись до ответа успеха.
- [x] SEO: metadata, canonical при реальном SITE_URL, OG, breadcrumbs, JSON-LD, sitemap, robots.
- [x] Юридические проекты, consent snapshot/hash, документы о запуске в РФ, Docker и инструкции.
- [x] Проверки: tests, typecheck, ESLint, production build, HTTP, desktop/mobile, реальные ошибки формы.

Review focus: нет настроенного хранилища — 503 без ложного успеха; consent=false — 400; внешний origin — 403; недопустимые данные не сохраняются; одинаковый ключ запроса не создает дубликат; demo-кейсы не индексируются; аналитика выключена до выбора.
