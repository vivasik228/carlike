# Hero service roller — 13.10.2026

Scope: только Hero и собственный компонент барабана. Дизайн-система, header, logo, навигация и остальные секции сохраняются. Фото остаются реальными, без ИИ.

Motion thesis: весь список движется на высоту одной строки; соседние названия показывают направление движения. Активная строка контрастна, края области скрыты маской. Длительность 560 мс, плавное ускорение и торможение. Автоматической смены нет. Одноразовый резервный таймер 700 мс завершает переход при приостановке rAF; очищается при завершении и размонтировании.

- Конфигурация девяти услуг с id, title, description, image, href.
- Три стабильные копии списка. На границе цикла сдвиг нормализуется на эквивалентную копию; видимые строки совпадают, DOM не перемонтируется.
- GSAP управляет transform списка, scale названий и opacity строк. Motion управляет только входом родительского .hero-copy и параллаксом .hero-image.
- Колесо: накопление, нормализация deltaMode, порог 60px, блокировка до окончания анимации, одна смена на поток событий до паузы 180 мс. Listener ограничен областью барабана.
- Touch: короткий вертикальный свайп 44–180px за ≤800 мс переключает услугу. Passive listeners и pan-y сохраняют нативный скролл; длинный жест прокручивает страницу.
- Кнопки и клавиши ArrowUp/ArrowDown; Enter открывает активную услугу. Reduced motion: мгновенная смена без пространственной анимации.
- Метаданные обновляются в одном событии выбора; область описания фиксирована. Для будущих локальных изображений поддерживается crossfade поверх постоянного poster.
- Проверить тестами цикл в обе стороны, deltaMode, инерцию, lock и жесты; в браузере — движения, кнопки, клавиши, колесо, скролл снаружи, 320px и длинные названия. TypeScript, lint, production build и существующие тесты.
