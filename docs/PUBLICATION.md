# Публичная демонстрация и исходники

GitHub: https://github.com/vivasik228/carlike

Демонстрация проекта: https://vivasik228.github.io/carlike/

`main` содержит полное приложение Next.js с серверным приёмом заявок. `gh-pages` содержит отдельную статическую сборку для просмотра интерфейса. В публичной демонстрации нет полей сбора данных, обработчиков API и счётчика аналитики; размещение не включает коммерческий приём заявок. Видимая плашка сообщает о режиме демонстрации. Страницы остаются noindex.

Статическую версию генерирует `scripts/export-public.mjs` в отдельной рабочей копии; исходное приложение и локальная production-сборка не изменяются. Фото, пути Next assets и ссылки учитывают `/carlike`. Юридические страницы в демоверсии являются статическими проектами документов.

Повторная сборка (укажите новый пустой каталог):

```sh
node scripts/export-public.mjs --base-path /carlike --output <абсолютный-путь>
```

Готовое содержимое каталога размещается в ветке `gh-pages`, источник GitHub Pages — корень этой ветки. Файл `.nojekyll` сохраняется. Секреты, `.env`, рабочая БД, node_modules и сборочный кэш в исходники не включаются.

Для полного коммерческого запуска используйте Node-сервер и требования `LAUNCH-RU.md`; GitHub Pages используется только для демонстрации проекта.
