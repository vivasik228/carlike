# Перед коммерческим запуском

Этот проект содержит техническую основу сбора заявок и редактируемые проекты документов. Он не подтверждает юридическое соответствие фактической деятельности оператора.

1. Установить фактического оператора; заполнить наименование, ИНН, ОГРН/ОГРНИП, адрес, email и срок хранения. Юристу проверить политику, самостоятельное согласие, цели, основания, сроки, привлечение обработчиков, права субъектов и обязанности по уведомлению Роскомнадзора.
2. Выбрать сервер в РФ с постоянным диском. Зафиксировать размещение основной БД, резервных копий, логов и CRM; проверить договоры. STORAGE_REGION=RU — настройка, а не доказательство расположения сервера.
3. Установить TLS на reverse proxy; закрыть прямой доступ к порту приложения. Ограничить доступ к базе, резервным копиям и ключу. TRUST_PROXY=true допустим только когда proxy удаляет входящий X-Real-IP и заменяет его адресом клиента.
4. Создать ключ AES-256; хранить отдельно от базы. Копировать ключ в защищённое резервное хранилище в РФ. Потеря ключа означает потерю возможности прочитать заявки. Ротация требует пере-шифрования старых записей; простая замена ключа не работает.
5. Утвердить регламент просмотра заявок, исполнения обращений, уничтожения, резервного копирования, восстановления и инцидентов. SQLite подходит одному серверу; для нескольких экземпляров заменить репозиторий на российскую PostgreSQL-инфраструктуру с общей защитой от частых запросов.
6. После проверки заполнить LEGAL_APPROVED=true. Юридические страницы и API читают серверные реквизиты в runtime. Форма получает hash текущего текста; при смене редакции сервер отклоняет устаревшую форму. Production-API также требует TRUST_PROXY=true, TLS-домен, ключ и RU-хранилище. Перед публикацией проверить тестовое сохранение и чтение согласия.
7. Настроить официальный домен, Яндекс Вебмастер, региональность Казань и связь с существующей карточкой Яндекс Бизнеса. Идентификатор Метрики подключить после проверки условий, раскрытий и настроек; до выбора пользователя счетчик не загружается.
8. Карта по умолчанию — ссылка. При желании получить embed URL из официальной карточки через «Поделиться → Код карты», проверить условия встраивания и заполнить NEXT_PUBLIC_MAP_EMBED_URL. Карта загружается по действию посетителя.
9. Добавить настоящие фотографии компании, реальные кейсы и подтвержденный режим работы. Демопроекты помечены и исключены из sitemap. Не публиковать цены, рейтинг, стаж, гарантии, сертификаты и аккаунты мессенджеров без подтверждения.

Исследованные источники:
- Информация Управления Роскомнадзора о самостоятельном согласии и обязанностях оператора, опубликованная органом местного самоуправления: https://pmr.tomsk.ru/publication/upravlenie-roskomnadzora-po-tomskoj-oblasti-informiruet
- Портал персональных данных Роскомнадзора: https://pd.rkn.gov.ru/
- Референс дизайна: https://quattro-dt.de/

Актуальные обязанности, формы уведомлений и редакции норм необходимо повторно проверить по официальным источникам при запуске. Автоматическое удаление по сроку не настроено: срок пока не утверждён. Исполняйте утверждённый регламент через серверный CLI и обработку резервных копий.
